Spotify Tracking Project
9/24/2025
-------------------------------
Description:
This is a personal program using the Spotify API to track all of my listening history 
It runs a Github action workflow every 2 hours to pull my 50 most recently listened
to songs, and then adds them to a cloud database I have saved on my google drive
Then once a day it runs an action to read from my database and configure the data
into a JSON that presents the data into readable tables on the Github page for 
this project at vanman119.github.io/Music_Project

Currently working on Version 2, which will be ran on my own device and not github actions
